## Fitur saat ini

- Pilihan **mata uang: USD atau IDR** (Rupiah)
- Pilihan **Top 10 / 20 / 50 koin** berdasarkan kapitalisasi pasar
- **💼 Portofolio tracker** — input holding (jumlah + harga beli USD),
  hitung P&L, lihat alokasi, unduh CSV
- **📈 Perbandingan multi-koin** — grafik 7 hari hingga 5 koin dengan
  mode normalisasi (base=100) atau harga mentah
- **🔍 Pencarian koin** — filter tabel & CSV berdasarkan nama atau simbol
- **💱 Konverter Koin** — konversi antar koin, USD, dan IDR dengan
  tombol tukar aset dan kurs live
- **⭐ Watchlist** — tandai koin favorit, tersimpan permanen di `watchlist.json`
- **📄 Laporan PDF mingguan** — unduh ringkasan pasar (top-N + disclaimer)
- Ringkasan **3 koin teratas** (harga + perubahan 24 jam)
- Tab **Gainers & Losers** — 5 koin naik/turun terbesar 24 jam,
  plus scatter plot perubahan vs volume
- **Grafik harga 7 hari** (Plotly) untuk koin yang dipilih
- **Tabel data pasar** untuk semua koin yang ditampilkan
- **Ekspor CSV** untuk semua koin dan untuk watchlist
- **Mode Demo** untuk situasi offline / API bermasalah
